# 🤖 Бот Сетевой магистратуры МИИГАиК

> 🎓 Разработано для студентов и сотрудников [МИИГАиК](https://www.miigaik.ru/)

Официальный Telegram-бот Сетевой магистратуры Московского государственного университета геодезии и картографии (МИИГАиК).  
Предоставляет быстрый доступ к информации по учебе, документам, техподдержке, финансам, партнёрам и контактам — всё в одном интерфейсе!

## 🌟 Возможности

- 📚 Раздел **«Учёба»** — расписания, материалы, регламенты  
- 📑 **Документы и административные вопросы** — зачисление, справки, отчисление  
- 💻 **Техническая поддержка** — помощь с платформой, доступами, аккаунтами  
- 💰 **Финансовые и социальные вопросы** — оплата, стипендии, льготы  
- 🌍 **Университеты-партнёры** — информация об университетах-партнерах  
- 👥 **Контакты и команда** — кто за что отвечает  
- ❓ **Часто задаваемые вопросы (FAQ)** — ответы на типичные запросы  

Интерфейс реализован через удобные **inline-кнопки** с поддержкой навигации «Назад» и «Домой».

## Технологии

- **Язык программирования**: Python 3.9
- **Библиотеки**:
  - *`python-telegram-bot`*: для работы с Telegram API
  - *`python-dotenv`*: для работы с переменными окружения
  - *`logging`*: для ведения логов
- **Сторонние инструменты**: 
  - *`Docker`*: проект вместе с необходимыми системными библиотеками и зависимостями упакован в контейнер

## Как запустить

Для начала склонируйте проект в свой репозиторий, после чего разверните его на своем компьютере.
Переходим в папку  проекта:
```
cd TG_bot_miigaik_v2
```
Cоздаем и активируем виртуальное окружение:
```
python3 -m venv env
```
* Если у вас Linux/macOS
    ```
    source env/bin/activate
    ```
* Если у вас windows
    ```
    source venv/Scripts/activate
    ```
Обновить пакетный менеджер pip:
```
python3 -m pip install --upgrade pip
```
Установить зависимости из файла `requirements.txt`:
```
pip install -r requirements.txt
```
Создайте файл `.env` и укажите в нем следующие переменные:
```
TELEGRAM_TOKEN_BOT=<ваш токен Telegram-бота>
```
> 💡 Убедитесь, что файлы `content.py` и `.env` находятся в корне проекта.
Запустить проект:
```
python tg_bot.py
```
